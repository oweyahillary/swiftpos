## 5. Failed attempts / lessons (so the next session skips them)

- **A test that never exits hangs CI silently.** `test-migration-104` passed its 8 assertions
  but its `ok()` didn't `await` the async bodies, so an in-flight `db.exec` raced `db.close()` and
  the process never exited — the sequential, timeout-less runner then stalled the CI job **~30
  minutes**. Two fixes: `await` the assertions (hotfix), and give the runner a **per-test
  timeout** (A305). Lesson: any test runner on a money system needs a per-test timeout.
- **`npm version` ran twice → a phantom `0.6.2`.** The global npm config has `git-tag-version=false`,
  so `npm version` bumps `package.json` but doesn't commit/tag; running it twice over-bumped, and
  the register **Tree row wasn't trued**, so `check-register-consistency` went red on `dev`. Lesson:
  the **Tree bump belongs in the release commit**, and run `npm version` once (or bump the file by hand).
- **Register drift across unpushed deliveries.** Several deliveries (`-l/-n/-o/-p`) sat unpushed on
  divergent bases, each editing the register; the counts diverged. Fixed by rebuilding the register
  from `origin/dev`'s exact content and shipping **one consolidated `-q`**. Lesson: push deliveries
  promptly, or consolidate; never stack register edits on stale bases.
- **Four register items were built-but-mislabeled** (A276 kitchen drinks = data/config; A277 CTL =
  missing field; A278 = poll present, reload missing; A19 = relay present, note wrong). Lesson: the
  open P1/P2 list is substantially **verification/labeling debt**, not missing code — trace the
  source before building.
- **Delivery-format slips early on** (used `git add -A`; shared flattened loose files instead of a
  repo-mirroring zip) — corrected; rules 1 and the `-A` ban held.
