## What changes
- **A product can be shown on chosen days only** (`products.show_days`; none = every day, as before). On those days it is
  on the POS grid (till and web POS) and the customer QR menu. On any other day it is off the grid and the QR menu, but a
  **search** finds it and it **sells at its normal price**; scanning a barcode / PLU works any day.
- **Where it is set:** the web — Products → edit → "Show on the POS on" (day buttons); or the menu upload's new
  `show_days` column ("Tue, Thu"; DELETE = every day). The till's own Manager → Menu editor has no day buttons — set days on
  the web; the till keeps them.
