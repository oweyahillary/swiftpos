## 8. The pattern, restated

§L of the register says it: **two things that must agree, with nothing comparing
them.** Every item closed today was an instance, and so was every mistake I made
closing them.

The cloud enforces permission keys and the till enforces roles (A59). The
migrations declare a permission set and the database holds another (A57). The
register's header declares a count and its body holds another (A60). A migration
qualifies one table name and not the next (A62). A gate scans for one call form
while the code uses two (A56's own defect).

What worked today was the same thing that worked on 08-10: **running it.** The
race in A55 was proven by racing it, not by reading the SQL. A62 was reproduced
under `search_path = ''` before it was fixed. Every gate that passed by not
looking was caught by mutation, and two of those mutations had to be run three
times before they were actually applied.

Tomorrow's desktop work has no bench that can run it. **That is the single
biggest risk in the plan**, and it is why the Windows machine is not optional.
