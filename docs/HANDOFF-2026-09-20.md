## 5. Failed attempts / lessons (so the next session skips them)

- **`npm run build` fails at `electron-builder`** ("app.asar … dist/main/index.js
  not found"). Root cause: the `build` script runs `electron-builder` with **no
  `--config`**, i.e. not the real `electron-builder.config.js` used by
  `pack:*`/`release:*`. **The real build path — `npm run build:all` then
  `npm run pack:dir` — works.** The bare `build` script is stale/legacy.
  *Proposed (own ID): repoint `"build"` to `"npm run build:all"` or delete it.*
- **Patch drift.** Applying patches onto an **uncommitted, stacked** working tree
  failed repeatedly (context lines no longer matched). Lesson adopted mid-session:
  for churny files (`PinPage.tsx`) ship **full-file drop-ins**, keep patches only
  for stable files, and **commit after each accepted change**.
- **`build-out/` nearly committed.** A `git add -A` swept 358k lines of packaged
  Electron output into a commit; reverted with `git reset --soft`. Lesson:
  **stage explicit paths, never `-A`**; `apps/desktop/build-out/` + `dist/` are
  now gitignored.
- **Heredoc truncation.** Pasting a long doc via `cat > … << EOF` truncated when
  the terminal fused the closing `EOF`. Lesson: deliver docs as files, not paste.
- **Register doc-refs.** Citing `A295-SLICE1C-UPLOAD-VALIDATION.md` in the
  register turned `check-doc-refs` red until the file was actually added to
  `docs/`. Lesson: a cited doc must exist in the tree.
- **Stale duplicate branch.** First push went to `a295-slice1a` **before 1c was
  committed** (1c was still unstaged). Re-pushed complete work to `a295-branding`.
  `a295-slice1a` is missing 1c — delete it, do not merge it.
