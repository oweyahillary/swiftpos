# Screenshots

Review shots of the website (`apps/website`, local build) and of the dashboard's Analytics page, all with made-up demo
data ("Mama Lishe Grill"). They are taken after each build session and saved as WebP to keep the repo light.

| File | What |
|---|---|
| `site-<page>-desktop.webp` | The website page at 1440 px |
| `site-<page>-phone.webp` | The same page at 390 px |
| `app-analytics-dark.webp`, `-light`, `-phone` | The dashboard's Analytics page (A558, A560 stock cards, A561 run-out card, no-cost call-out and area tiles), demo data; phone at 390 px |
| `app-analytics-stock.webp` | A561: the Stock area — what runs out soonest, what you throw away most (Westlands, demo data) |
| `app-analytics-customers.webp` | A561: the Customers area — new and returning, regulars gone quiet, best customers, the order-type mix, the average bill |
| `app-analytics-costs.webp` | A561: the Costs area — the items without a cost (top), food cost, the thinnest margins, costs that went up |
| `app-analytics-tabs.webp` | A561: the "Dig into the details" tiles — dark, light, the sticky compact bar while scrolling an area, and the phone row |
| `app-analytics-branches.webp` | A565: the Branches area (three branches, demo data) — a falling branch flagged, the branches side by side, the stock moves to consider in words (no quantity) |
