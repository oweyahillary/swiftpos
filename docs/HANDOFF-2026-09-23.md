The bump is a THREE-part change or CI goes red: `apps/desktop/package.json` + `package-lock.json`
+ the register Tree row. Sequence that works from the repo root:
```bash

# edit docs/AUDIT-REGISTER.md Tree row: desktop **vX.Y.Z**
node scripts/check-register-consistency.mjs

git commit -m "desktop: vX.Y.Z (…)" && git tag vX.Y.Z && git push origin dev && git push origin vX.Y.Z
```
